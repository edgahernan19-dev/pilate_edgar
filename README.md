De manera general, la página web es una Landing Page interactiva para tu estudio de Pilates Reformer llamado LIGNÉE. Funciona con dos vistas principales:

Vista para el Cliente: Donde los usuarios pueden ver la información del lugar, conocer lo que ofrecen, ver las clases disponibles con sus horarios, ver productos a la venta, y contactarte directamente por WhatsApp para agendar o comprar.

Vista de Administrador: Un panel oculto donde tú (con usuario y contraseña) puedes agregar, modificar o eliminar en tiempo real las clases, horarios, productos e información del lugar sin necesidad de saber programar, gracias a su conexión con una base de datos (Firebase).
